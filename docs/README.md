# MyDE

Documentation for [mojochao/myde.emacs](https://github.com/mojochao/myde.emacs), a
literate Emacs configuration for Emacs 31.1+ on Linux and macOS.

Installation, the section layout, the binary gates, and the external tools each
section needs are all in the [repository README](https://github.com/mojochao/myde.emacs#readme).
This site holds the longer material that does not belong there.
