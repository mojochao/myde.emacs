# AGENTS.md — MyDE Emacs Configuration

Personal Emacs config (v29+) organized as a modular system with [XDG Base Directory Specification](https://specifications.freedesktop.org/basedir/basedir-spec-latest.html) compliance.
This directory is a symlink to `~/.config/emacs`.

**Portable to Emacs 30+:** Uses built-in `xdg.el` library for path management.

## Key facts

**Entry points:**
- `early-init.el` — Loaded first (rarely modified)
- `init.el` — Main config file (520 lines); loads `myde.el`, then all module `cfg.el` files
- `myde.el` — Core library (197 lines) with shared utilities and helpers
- `custom.el` — Auto-generated by Emacs (user customizations); loaded by init.el

**Module system:**
- Modules live in `myde/<category>-<name>/` with exactly two files: `lib.el` and `cfg.el`
- `init.el` loads only `cfg.el` files (via bare `load-file` calls around line 347-357)
- Each `cfg.el` has a `featurep` guard that loads its own `lib.el` (idempotent)
- Categories: `prog-*` (languages), `core-*` (infrastructure), `text-*` (formats)

**Feature symbols follow pattern:**
- `lib.el` provides: `myde-<category>-<name>`
- `cfg.el` provides: `myde-<category>-<name>-cfg`
- Example: `myde/prog-go/lib.el` provides `myde-prog-go`

## Conventions agents must honor

**When modifying or creating modules:**
- `lib.el` must begin with `(require 'myde)` and end with `(provide 'myde-<category>-<name>)`
- `cfg.el` must begin with a `featurep` guard loading its `lib.el`, end with `(provide 'myde-<category>-<name>-cfg)`
- `init.el` loads modules via `(load-file (expand-file-name "myde/<category>-<name>/cfg.el" user-emacs-directory))`
- All side effects (hooks, use-package, etc.) go in `cfg.el`; pure definitions in `lib.el`

**Keybinding prefixes (language modules):**
- `C-c e` — LSP/eglot (all languages)
- `C-c t` — Tests (language-specific)
- `C-c i` — REPL/interactive (language-specific)
- `C-c d` — Debug/dape (global)

**Shared tools used across modules:**
- `treesit`, `eglot`, `dape` — Base config in `init.el`; language-specific additions via extra `use-package` declarations in module `cfg.el` with `:ensure nil`
- Multiple `use-package` blocks for the same package accumulate (idiomatic)
- `myde/eglot-add-workspace-config` helper in `myde.el` for upserting LSP workspace config without clobbering other modules

## Implementation details

**Module load order (init.el lines 347-357):**
1. Core modules (`core-*`)
2. Programming language modules (`prog-*`)
3. Text format modules (`text-*`)

**Module loading is idempotent:** Each `cfg.el`'s `featurep` guard prevents re-evaluation.

**XDG Base Directory compliance:**
- Backups → `$XDG_STATE_HOME/emacs/backup/` (default: `~/.local/state/emacs/backup/`)
- State files (recentf, projects, history) → `$XDG_STATE_HOME/emacs/`
- Packages/data (elpa, transient, tree-sitter) → `$XDG_DATA_HOME/emacs/` (default: `~/.local/share/emacs/`)
- Cache (eln-cache, url) → `$XDG_CACHE_HOME/emacs/` (default: `~/.cache/emacs/`)
- Uses Emacs 29.1+ `xdg.el` library functions; no custom path logic needed

**Backup and custom handling:**
- Backups stored in XDG state directory (created automatically by init.el)
- `custom.el` path set at init.el startup; loaded if it exists

**macOS-specific behavior:**
- Pixel scrolling enabled in GUI
- Command and option keys swapped to match Linux layout
- Menubar preserved only in GUI (removed elsewhere)

**LSP configuration:**
- Subprocess read buffer increased to 1 MiB (line 91 in init.el) for LSP throughput
- `eglot-autoshutdown` enabled
- Per-language servers configured in their respective `prog-*/cfg.el` files
